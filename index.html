Какво представлява ShkoloHundred?

ShkoloHundred е браузърно разширение, което ти позволява да променяш оценките в дневника локално — само на твоя компютър. Нищо не се записва в Shkolo, нищо не се изпраща към сървъри. Просто „какво ако“ инструмент.

Локални промени

Всичко остава само при теб. Няма съхранение в облак.

Красив интерфейс

Модерен popup, цветове като в Shkolo, анимации и плавни преходи.

Бързо нулиране

Един бутон — всички оценки се връщат към оригиналните.

Безопасно

Не променя реални оценки. Само визуално.

Как да инсталираш ShkoloHundred

1. Изтегли разширението

Натисни бутона „Изтегли разширението“ горе.

2. Разархивирай ZIP файла

Важно: Първо трябва да разархивираш ZIP файла. Ако не го разархивираш, Chrome няма да го зареди.

3. Инсталация в Google Chrome

  1. Отвори Chrome.
  2. Влез в: chrome://extensions
  3. Включи Developer mode / Режим за разработчици (горе вдясно).
  4. Натисни Load unpacked / Зареди разархивирана папка.
  5. Избери папката, която разархивира.

4. Инсталация в Microsoft Edge

  1. Отвори Edge.
  2. Влез в: edge://extensions
  3. Включи Developer mode.
  4. Натисни Load unpacked.
  5. Избери разархивираната папка.

5. Инсталация в Brave

  1. Отвори Brave.
  2. Влез в: brave://extensions
  3. Включи Developer mode.
  4. Натисни Load unpacked.
  5. Избери разархивираната папка.

6. Инсталация в Opera

  1. Отвори Opera.
  2. Влез в: opera://extensions
  3. Включи Developer mode.
  4. Натисни Load unpacked.
  5. Избери разархивираната папка.

Готово!

След инсталация ще видиш иконата на ShkoloHundred горе вдясно. Отвори дневника в Shkolo и започни да променяш оценки локално.
