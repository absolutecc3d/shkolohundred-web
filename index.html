Функции

ShkoloHundred е създаден за ученици, които искат да видят как би изглеждал дневникът им с различни оценки — без да променят реалните.

Локални промени

Нищо не се изпраща към Shkolo. Всичко е само визуално и само на твоя компютър.

Красив интерфейс

Модерен popup, плавни анимации и цветове като в Shkolo.

Бързо нулиране

Един бутон връща всички оценки към оригиналните им стойности.

Безопасно

Не променя реални оценки. Не изпраща заявки. Не събира данни.

Инсталация

Следвай стъпките за да добавиш ShkoloHundred към браузъра си.

1. Изтегли и разархивирай

Изтегли ZIP файла от бутона горе.

Важно: Разархивирай ZIP файла. Браузърите не приемат ZIP директно.

2. Google Chrome

  1. Отвори Chrome.
  2. Напиши: chrome://extensions
  3. Включи Developer mode.
  4. Натисни Load unpacked.
  5. Избери разархивираната папка.

3. Microsoft Edge

  1. Отвори Edge.
  2. Напиши: edge://extensions
  3. Включи Developer mode.
  4. Load unpacked → избери папката.

4. Brave

  1. Отвори Brave.
  2. Напиши: brave://extensions
  3. Включи Developer mode.
  4. Load unpacked → избери папката.

5. Opera

  1. Отвори Opera.
  2. Напиши: opera://extensions
  3. Включи Developer mode.
  4. Load unpacked → избери папката.

6. Готово!

Отвори Shkolo дневника и кликни върху оценка — popup‑ът ще се появи.
