Защо ShkoloHundred?

Разширението е създадено за „какво ако“ сценарии — да видиш как биха изглеждали оценките ти, без да променяш реалния дневник.

Локални промени

Всичко се случва само в твоя браузър. Няма изпращане към сървъри, няма промяна на реални оценки.

Интуитивен интерфейс

Клик върху оценка отваря popup с цветна скала от 2 до 6. Анимации правят смяната плавна и приятна.

Бързо нулиране

Един бутон връща всички променени оценки към оригиналните им стойности, с анимация при връщане.

Безопасно за дневника

ShkoloHundred не изпраща заявки към Shkolo за промяна на оценки. Всичко е чисто визуално.

Инсталация на ShkoloHundred

Следвай стъпките по-долу, за да добавиш разширението в любимия си браузър.

1. Изтегли и разархивирай

Натисни бутона „Изтегли разширението“ горе. Ще получиш ZIP файл.

Важно: Разархивирай ZIP файла в папка (например ShkoloHundred). Браузърът не може да зареди директно ZIP.

2. Google Chrome

  1. Отвори Chrome.
  2. В адресната лента напиши: chrome://extensions
  3. Включи Developer mode / Режим за разработчици (горе вдясно).
  4. Натисни Load unpacked / Зареди разархивирана папка.
  5. Избери папката, в която разархивира ZIP файла.

3. Microsoft Edge

  1. Отвори Edge.
  2. В адресната лента напиши: edge://extensions
  3. Включи Developer mode.
  4. Натисни Load unpacked.
  5. Избери разархивираната папка.

4. Brave

  1. Отвори Brave.
  2. В адресната лента напиши: brave://extensions
  3. Включи Developer mode.
  4. Натисни Load unpacked.
  5. Избери разархивираната папка.

5. Opera

  1. Отвори Opera.
  2. В адресната лента напиши: opera://extensions
  3. Включи Developer mode.
  4. Натисни Load unpacked.
  5. Избери разархивираната папка.

6. Използване

След инсталация ще видиш иконата на ShkoloHundred горе вдясно.

Отвори дневника в Shkolo, кликни върху оценка и ще се появи popup за смяна. Бутонът „Reset all grades on this page“ връща всичко към оригиналното.
